SplitActionBars lets you separate Blizzard's action bars into groups by adding gaps between columns or rows. Your buttons and keybindings stay as they are. You choose where each gap goes and how much space it leaves.

## Features

- Add multiple gaps to a bar, each with its own spacing.
- Use horizontal, vertical or multi-row bars.
- Preview changes in Edit Mode, then save or revert them with Blizzard's controls.
- Keep separate gap settings for each layout and bar.

If you reduce a bar's rows or columns, gaps that no longer fit remain saved. They return when the bar has room for them again.

The addon is available in English, German, French, Spanish and Italian.

## Installation and use

SplitActionBars currently supports WoW Forever.

1. Install SplitActionBars through an addon manager, or copy the `SplitActionBars` folder into your client's `Interface/AddOns` directory manually.
2. Enable the addon, open Edit Mode and select an action bar.
3. Choose **Add new gap...** in the SplitActionBars dropdown.
4. Choose columns or rows, the position and the spacing.
5. Save the layout with Blizzard's controls, or revert the changes.

Spacing sets the entire gap between the adjacent columns or rows, rather than adding to the bar's normal icon spacing. The addon leaves your bars unchanged until you add a gap.

Configuration changes are unavailable during combat.
